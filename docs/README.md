# FYI Lab — Project README

FYI Lab is a one-person data visualization studio site built with React + Vite. It showcases projects, services, and (eventually) written articles.

## Quick Start

```bash
cd fyi-lab-react
npm install
npm run dev      # → http://localhost:5173
```

## Tech Stack

| Layer | Tool |
|---|---|
| Framework | React 19 + Vite 7 |
| Language | TypeScript |
| Routing | React Router v7 |
| i18n | react-i18next + i18next |
| Animation | Framer Motion + native Canvas API |
| Styling | Vanilla CSS (CSS variables) |

## Key Commands

| Command | Purpose |
|---|---|
| `npm run dev` | Start local dev server |
| `npm run build` | Production build → `dist/` |
| `npm run preview` | Preview production build locally |
| `npm run lint` | ESLint check |
